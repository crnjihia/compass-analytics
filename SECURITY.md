# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, please **do not** publish it publicly. Instead, disclose it privately by emailing the security contact at [INSERT SECURITY EMAIL]. Include:

- A brief description of the issue
- Steps to reproduce (if applicable)
- Any relevant logs or screenshots
- Your contact information (optional, for follow‑up)

We will acknowledge receipt of your report within 48 hours and work with you to resolve the issue as quickly as possible.

## Supported Versions

We support the latest released version of the project. Older releases may contain unpatched bugs and are not supported.
